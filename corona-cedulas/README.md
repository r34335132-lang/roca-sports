# Corona Soccer Park · Generador de Cédulas

Aplicación Next.js + React + TypeScript + Tailwind para crear cédulas de jugadores editables, fieles al diseño de referencia de Corona Soccer Park.

## Scripts

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Funciones

- Editar nombre, equipo, categoría, posición, número/ID y temporada
- Subir fotografía
- Vista previa en tiempo real
- Descargar PNG
- Descargar PDF
- Imprimir
